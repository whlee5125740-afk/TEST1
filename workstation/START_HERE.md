# 시작 안내

1. README.md에서 과제 구성과 미확인 항목을 봅니다.
2. docs/PC_SETUP.md로 PC 준비 상태를 확인합니다.
3. docs/RUNBOOK.md를 Ubuntu 터미널에서 순서대로 실행합니다.
4. evidence/README.md 안내대로 실제 로그와 화면을 저장합니다.
5. docs/INTERVIEW.md는 별도 면담 연습 자료입니다.
6. 실제 확인한 체크표와 GitHub 주소로 README를 보완한 뒤 제출합니다.

이 패키지는 완성된 소스·문서와 사용자 PC 검증 절차를 제공합니다. PC 설치, 실제 Docker 실행, GitHub 업로드가 완료된 제출본은 아직 아닙니다.
